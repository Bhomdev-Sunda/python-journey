# Day11 Notes

## What is a Function?
A function is a reusable block of code that performs a specific task.

## Why Functions are Used
- Reduce repetition
- Improve readability
- Reusable code
- Easier maintenance

## Syntax
```python
def func():
    pass
```

## Function Definition
Use `def` keyword.

## Function Call
Call using function name with parentheses.

## Parameters vs Arguments
- Parameter: variable in definition
- Argument: actual value passed

## Types of Arguments
- Positional
- Keyword
- Default
- *args
- **kwargs

## Return Statement
`return` sends a value back.

## Local vs Global Variables
Local: inside function.
Global: outside function.

## Lambda Function
Anonymous one-expression function.

## Built-in Functions
print(), input(), len(), sum(), max(), min(), sorted(), type().

## Real-life Applications
Billing, ATM, Login, Student Management, APIs.

## Common Mistakes
- Forgetting to call function
- Confusing print and return
- Misusing globals

## Interview Questions

**What is a function?** Reusable block of code.

**Why do we use functions?** Reuse and modularity.

**Difference between parameter and argument?** Parameter is placeholder, argument is actual value.

**Difference between print() and return?** print displays; return sends value.

**What is variable scope?** Region where variable is accessible.

**What is a local variable?** Declared inside function.

**What is a global variable?** Declared outside function.

**What is a lambda function?** Small anonymous function.

**What are built-in functions?** Predefined Python functions.

**Can a function return multiple values?** Yes, using commas.

## Key Takeaways
- Functions improve code quality.
- Use return for reusable results.
- Prefer local variables.
